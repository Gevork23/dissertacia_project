# TASKS

## Статусы

- `done` — выполнено
- `partial` — начато, но не закрыто
- `planned` — запланировано

## Фаза 0 — фиксация замысла проекта

**Статус:** `done`

Фаза закрыта: границы проекта, основной сценарий, архитектурный фокус и базовая документация согласованы.

## Фаза 1 — базовая платформа и данные

**Статус:** `done`

Закрыто:

- модели `Document` и `DocumentVersion`;
- загрузка версий документов;
- поддержка TXT / DOCX / PDF;
- извлечение текста;
- нормализация;
- автоматическое построение чанков после загрузки версии;
- базовые автотесты ingestion-сценариев.

## Фаза 2 — сравнение редакций

**Статус:** `done`

Закрыто:

- сравнение двух версий одного документа;
- обработка added / removed / modified / moved;
- объяснимое выделение изменений;
- покрытие diff-логики тестами;
- demo-примеры для сравнения.

## Фаза 3 — выжимка и генерация тестов

**Статус:** `done`

- покрытие summary/quiz-логики тестами.

## Фаза 4 — утверждение, прохождение, результаты

**Статус:** `done`

## Приоритетное правило

Если задача:

- не усиливает основной сценарий;
- мешает срокам;
- усложняет демонстрацию;
- не нужна для защиты и MVP,

то она по умолчанию не приоритетна и выносится за пределы текущего защищаемого контура.
