# Defense Checklist

## Перед запуском защиты

- [ ] заполнен `infra/.env`
- [ ] сервисы поднимаются через `docker compose up --build`
- [ ] endpoint `http://localhost:8000/api/health/` отвечает `200`
- [ ] demo UI открывается по `http://localhost:8000/`
- [ ] выполнена команда `python manage.py load_demo_pairs`
- [ ] на dashboard видны demo-документы
- [ ] можно открыть сравнение версий
- [ ] можно создать и утвердить тест
- [ ] можно пройти тест и открыть отчёт

## Непосредственно перед комиссией

- [ ] открыта вкладка `/demo/`
- [ ] открыта резервная вкладка `/demo/quizzes/`
- [ ] в системе уже есть хотя бы один утверждённый тест
- [ ] в системе уже есть хотя бы одна сохранённая попытка
- [ ] проверен локальный адрес и сетевой адрес
- [ ] подготовлен краткий устный сценарий на 5–10 минут
