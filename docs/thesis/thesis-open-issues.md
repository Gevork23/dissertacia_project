# Thesis Open Issues

## 1. Требуются внешние источники

Нужно подобрать реальные источники для утверждений, перечисленных в `docs/thesis/bibliography-placeholders.md`. Нельзя оставлять placeholders `[источник: ...]` в финальной версии диссертации.

Основные категории источников:

- электронный документооборот;
- document management systems;
- document comparison / diff algorithms;
- legal NLP;
- LLM hallucinations / reliability;
- human-in-the-loop systems;
- employee training / compliance learning;
- evaluation methodology for NLP/document systems.

## 2. Требуется финальная нумерация рисунков и таблиц

После сборки полного текста нужно проверить:

- сквозную нумерацию таблиц глав 1–3;
- нумерацию рисунков 1.x, 2.x, 3.x;
- соответствие подписей требованиям кафедры;
- корректность ссылок в тексте на рисунки и таблицы;
- необходимость переноса больших таблиц главы 3 в приложения.

## 3. Требуется проверка формулировок с научным руководителем

Рекомендуется согласовать:

- объект исследования;
- предмет исследования;
- цель работы;
- перечень задач;
- формулировку научной новизны / научной значимости;
- допустимость англоязычных технических терминов в основном тексте.

## 4. Требуется вычитка терминологии

Перед финальной сборкой проверить единообразие:

- `comparison` / `diff` / «сравнение редакций»;
- `significance` / `importance` / «значимость»;
- `summary` / «человеко-читаемая выжимка»;
- `quiz` / «тест» / «контрольно-обучающие материалы»;
- `structural chunking` / «структурное разбиение»;
- `human-in-the-loop` / «участие ответственного лица».

## 5. Требуется финальная сборка введения, заключения и списка литературы

Фаза 24 не включает введение, заключение и финальную библиографию. Эти материалы должны быть подготовлены отдельно после утверждения основной части.
