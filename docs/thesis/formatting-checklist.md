# Formatting Checklist

## 1. Общая структура

- [ ] Титульный лист подготовлен по шаблону вуза / кафедры.
- [ ] Задание / аннотация / реферат добавлены, если требуются локальными правилами.
- [ ] Содержание сформировано автоматически или проверено вручную.
- [ ] Введение включено после содержания.
- [ ] Главы 1–3 идут в утверждённом порядке.
- [ ] Заключение включено после главы 3.
- [ ] Список литературы оформлен на основе реальных источников.
- [ ] Приложения добавлены после списка литературы.

## 2. Нумерация разделов

- [ ] Проверена нумерация глав: 1, 2, 3.
- [ ] Проверена нумерация подразделов: 1.1, 1.2, 2.1, 3.1 и т.д.
- [ ] Заголовки введения, заключения, списка литературы и приложений оформлены по требованиям кафедры.
- [ ] В содержании номера страниц соответствуют финальной версии.
- [ ] Нет дублирующихся или пропущенных номеров подразделов.

## 3. Рисунки

- [ ] Все рисунки имеют подписи.
- [ ] Нумерация рисунков согласована с главами: Рисунок 1.x, 2.x, 3.x.
- [ ] Все ссылки на рисунки в тексте проверены.
- [ ] Mermaid/ERD/PNG-диаграммы отрендерены в пригодном для вставки качестве.
- [ ] Экспериментальные графики главы 3 вставлены из `experiments/final_visuals/figures/`.
- [ ] Источник рисунка указан, если рисунок не является авторским.

## 4. Таблицы

- [ ] Все таблицы имеют номера и названия.
- [ ] Нумерация таблиц согласована с главами: Таблица 1.x, 2.x, 3.x.
- [ ] Большие таблицы проверены на читаемость.
- [ ] Решено, какие крупные таблицы перенести в приложения.
- [ ] Все ссылки на таблицы в тексте проверены.
- [ ] Значения экспериментальных метрик не изменены при переносе в финальный формат.

## 5. Формулы

- [ ] Формула `M = <E, N, S, C, P, G, R>` оформлена единообразно.
- [ ] Расшифровка всех элементов `E`, `N`, `S`, `C`, `P`, `G`, `R` присутствует рядом с первым употреблением.
- [ ] Если кафедра требует нумерацию формул, формула метода пронумерована.
- [ ] Все обозначения согласованы с текстом глав 1–3.

## 6. Ссылки на источники

- [ ] Все placeholders источников заменены реальными ссылками.
- [ ] Нет вымышленных библиографических записей.
- [ ] Все источники из текста присутствуют в списке литературы.
- [ ] Все источники из списка литературы реально используются в тексте.
- [ ] Оформление соответствует требованиям кафедры / ГОСТ.
- [ ] Для интернет-источников указаны URL и дата обращения, если это требуется.

## 7. Ссылки на рисунки и таблицы

- [ ] Все фразы «см. рисунок» и «см. таблицу» указывают на существующие объекты.
- [ ] Нет ссылок на удалённые или перенесённые таблицы.
- [ ] Номера в тексте совпадают с подписями объектов.
- [ ] Ссылки обновлены после финальной сборки DOCX/PDF.

## 8. Приложения

- [ ] Состав приложений согласован с научным руководителем.
- [ ] В приложения вынесены крупные схемы, ERD, дополнительные таблицы и фрагменты corpus, если это уместно.
- [ ] На каждое приложение есть ссылка в основном тексте, если это требуется правилами оформления.
- [ ] Приложения имеют заголовки и буквенную / числовую нумерацию.

## 9. Проверка языка и стиля

- [ ] Устранены разговорные формулировки.
- [ ] Согласованы русские и английские технические термины.
- [ ] Убраны избыточные повторы между введением, главой 1 и заключением.
- [ ] Проверены cautious claims: нет заявлений об универсальности, замене эксперта или гарантированном качестве LLM/quiz.
- [ ] Проверены орфография, пунктуация и единообразие сокращений.

## 10. Финальная проверка перед сдачей

- [ ] Научный руководитель проверил тему, цель, задачи, новизну и положения на защиту.
- [ ] Все замечания научного руководителя учтены.
- [ ] Антиплагиат / оригинальность проверены.
- [ ] Итоговый `.docx` или `.pdf` открыт и просмотрен вручную.
- [ ] Все страницы, поля, шрифты, интервалы и отступы соответствуют требованиям.
- [ ] Репозиторий и архив проекта не содержат случайных runtime-файлов, если они не нужны для демонстрации.
