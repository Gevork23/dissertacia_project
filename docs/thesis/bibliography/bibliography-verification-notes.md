## 4. Источники, которые не стоит использовать

- Случайные блоги, Medium-посты, SEO-обзоры СЭД и статьи без автора/даты не включались.
- ResearchGate использовался только как вспомогательный сигнал в поиске, но не как основной источник metadata, если была доступна страница издателя/университета/ACL/Springer/ACM.
- Непроверенные DOI/ISBN/страницы не добавлялись.

## 5. Замечания по ГОСТ-оформлению

- `bibliography-gost-draft.md` является черновиком, а не финальной ГОСТ-вычиткой.
- Для web sources указана дата обращения: 12.05.2026.
- Форматирование требует финальной проверки по методическим рекомендациям ДГТУ/кафедры.
- Для источников с DOI в финальном списке следует привести DOI в формате, принятом кафедрой.
- Для стандартов и официальных спецификаций организацию можно указывать как автора, если методичка допускает такой вариант.
