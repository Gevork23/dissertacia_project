# Final Submission Checklist

## 1. Содержательная готовность

- [ ] Полный текст диссертации собран из введения, глав 1–3, заключения, списка литературы и приложений.
- [ ] Цель, задачи, объект и предмет исследования согласованы между введением, главой 1 и заключением.
- [ ] Научная новизна не завышена и не заявляет универсальность метода.
- [ ] Положения на защиту соответствуют фактическим результатам проекта.
- [ ] Выводы главы 3 соответствуют экспериментальным артефактам.

## 2. Проверка научным руководителем

- [ ] Согласована формулировка темы.
- [ ] Согласованы объект, предмет, цель и задачи.
- [ ] Согласованы научная новизна и положения на защиту.
- [ ] Согласована достаточность synthetic evaluation corpus для MVP-оценки.
- [ ] Согласован состав приложений.
- [ ] Получены и учтены финальные замечания.

## 3. Библиография

- [ ] Подобраны реальные источники по всем high-priority bibliography gaps.
- [ ] Никакие источники не выдуманы.
- [ ] Ссылки оформлены по требованиям кафедры / ГОСТ.
- [ ] Все placeholders источников удалены из финального текста.
- [ ] Проверено соответствие внутритекстовых ссылок списку литературы.

## 4. Форматирование

- [ ] Титульный лист соответствует шаблону.
- [ ] Содержание обновлено.
- [ ] Нумерация глав, подразделов, рисунков, таблиц и формул проверена.
- [ ] Поля, шрифты, интервалы и отступы соответствуют требованиям.
- [ ] Все рисунки и таблицы читаемы в PDF/DOCX.

## 5. Антиплагиат / оригинальность

- [ ] Проверка оригинальности выполнена в требуемой системе.
- [ ] Заимствованные формулировки корректно процитированы.
- [ ] Технические фрагменты, таблицы и определения оформлены с источниками при необходимости.
- [ ] Итоговый процент оригинальности соответствует требованиям.

## 6. Демонстрация проекта

- [ ] Локальный запуск проекта проверен.
- [ ] Demo corpus и evaluation corpus доступны.
- [ ] Сценарий демонстрации согласован с содержанием диссертации.
- [ ] Не демонстрируются функции, которые не входят в MVP scope.
- [ ] Готово объяснение ограничений: no OCR, no enterprise RBAC, no legal expert replacement, optional LLM only.

## 7. Репозиторий и архив проекта

- [ ] Репозиторий не содержит случайных runtime-файлов, если они не нужны для сдачи.
- [ ] `.gitignore` проверен.
- [ ] `db.sqlite3`, `media/`, `uploads/`, `*.log`, `__pycache__/`, `.pytest_cache/` проверены как потенциальный мусор.
- [ ] Итоговый архив проекта содержит необходимые документы, код и experiment artifacts.
- [ ] В README описан актуальный scope MVP.

## 8. Презентация

- [ ] Подготовлена структура презентации: проблема, метод, архитектура, эксперименты, результаты, ограничения.
- [ ] В презентации используются только проверенные метрики.
- [ ] На слайдах нет заявлений об универсальности или замене эксперта.
- [ ] Готов слайд с `M = <E, N, S, C, P, G, R>`.
- [ ] Готов слайд с end-to-end result `0.8889` и bottleneck `pair_06_procedure_change`.

## 9. Документы к защите

- [ ] Финальный текст диссертации.
- [ ] Аннотация / реферат, если требуется.
- [ ] Отзыв / рецензия, если применимо.
- [ ] Презентация.
- [ ] Демонстрационные материалы.
- [ ] Архив проекта.
- [ ] Справка об оригинальности, если требуется.

## 10. Финальный контроль

- [ ] Все placeholders удалены или явно оставлены только в рабочей версии, не в финальной сдаче.
- [ ] Все метрики сверены с experiment artifacts.
- [ ] Все ограничения отражены в тексте и презентации.
- [ ] Финальный файл открывается на другом компьютере.
- [ ] Названия файлов понятны и не содержат временных пометок вроде `final_final`.
- [ ] Подготовлен краткий ответ на вопрос комиссии: «что именно является научным результатом работы?»
