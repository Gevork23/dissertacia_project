# Bibliography Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Недостаточно русскоязычных источников | medium | добавить учебники/ГОСТ/официальные документы после получения методички кафедры; не заменять ими ключевые peer-reviewed источники |
| Слишком много web sources | low | основной список состоит из научных статей, книг, стандартов; web-only оставлен только для industry report и официальных страниц |
| Источники по LLM слишком свежие и терминология нестабильна | medium | использовать survey papers и papers по factuality/RAG/self-check; избегать сильных утверждений о гарантиях |
| Нет прямого источника, полностью совпадающего с pipeline M=<E,N,S,C,P,G,R> | low | не искать фиктивный источник; оформить формулу как собственную разработку и ссылаться только на смежные document intelligence/HITL/AQG направления |
| SRC-DIFF-005 и SRC-ARCH-003 имеют неполные библиографические поля | medium | оставить needs verification; перед финальной сдачей проверить издательские записи или заменить |
| Источники по employee/compliance learning частично покрыты через AQG/assessment, а не через корпоративное обучение | medium | при необходимости добавить отдельный peer-reviewed источник по compliance training/LMS в Фазе 28 |
| ГОСТ-оформление может не совпасть с требованиями кафедры | high | сверить с методическими рекомендациями ДГТУ/кафедры; текущий файл считать только draft |
| Часть источников на английском языке может потребовать русскоязычного баланса | medium | после консультации с руководителем добавить 2–4 российских источника по СЭД/нормативным документам, только проверенные |
